1. Architecture Decisions Summary
All eight architecture decisions are recorded here as a quick reference. Each decision is documented in full in the section that follows.

2. Overall Architecture
Space Crusade uses a strict two-layer architecture. The simulation layer contains all game logic as pure C# with no Unity dependency. The view layer is Unity — MonoBehaviours, GameObjects, renderers, animators, and input. The two layers communicate through a thin interface.
2.1 Layer Responsibilities

Simulation

View

🔷  Pattern: Model-View separation:  The simulation is the Model. Unity GameObjects are the View. The View reads from the Model every frame to update visuals. The Model never reads from the View. This is strict — any violation creates untestable code.

2.3 Simulation Entry Point
The simulation is created and owned by a single MonoBehaviour that acts as the bridge between Unity&apos;s lifecycle and the simulation loop.
public class GameManager : MonoBehaviour {
private Simulation _sim;
private ViewLayer  _view;
private float      _accumulator;
private const float TICK = 1f / 20f; // 50ms
void Start() {
_sim  = new Simulation();
_view = new ViewLayer(_sim);
_sim.Initialise();
}
void Update() {
// Accumulator pattern — Decision 3
_accumulator += Time.deltaTime;
while (_accumulator &gt;= TICK) {
_sim.Tick(TICK);
_accumulator -= TICK;
}
float alpha = _accumulator / TICK;
_view.Render(alpha); // interpolated visuals
}
}

public class Construct {
public int              Id;
public string           Name;          // player-assigned or auto-generated
public ConstructType    Type;          // Base, Vehicle, Droid, Orbital, Outpost

public void Reclassify(BlockTable blocks) {
bool hasSeat       = blocks.AnyInSet(BlockIds, b =&gt; b.Definition.FunctionalType == FunctionalType.Seat);
bool hasPropulsion = blocks.AnyInSet(BlockIds, b =&gt; b.Definition.FunctionalType == FunctionalType.Propulsion);
bool hasPower      = blocks.AnyInSet(BlockIds, b =&gt; b.Definition.PowerOutputKW &gt; 0);
bool hasFoundation = blocks.AnyInSet(BlockIds, b =&gt; b.Definition.FunctionalType == FunctionalType.Foundation);
bool hasProduction = blocks.AnyInSet(BlockIds, b =&gt; b.Definition.Category == BlockCategory.Production);
IsAnchored  = hasFoundation;
IsPilotable = hasSeat &amp;&amp; hasPropulsion &amp;&amp; hasPower;
Type = (IsPilotable &amp;&amp; !IsAnchored) ? ConstructType.Vehicle
: (IsAnchored &amp;&amp; hasProduction) ? ConstructType.Base
: IsAnchored                    ? ConstructType.Outpost
: ConstructType.Structure;
}
}

4. System Communication
4.1 Event Bus
The event bus carries discrete events — things that happened once. Systems subscribe at construction. Events are fired synchronously during simulation ticks. The view layer also subscribes to drive audio and visual effects.
public static class EventBus {
private static readonly Dictionary&lt;Type, List&lt;Delegate&gt;&gt; _handlers = new();
public static void Subscribe&lt;T&gt;(Action&lt;T&gt; handler) {
if (!_handlers.ContainsKey(typeof(T)))
_handlers[typeof(T)] = new List&lt;Delegate&gt;();
_handlers[typeof(T)].Add(handler);
}
public static void Publish&lt;T&gt;(T evt) {
if (_handlers.TryGetValue(typeof(T), out var handlers))
foreach (var h in handlers)
((Action&lt;T&gt;)h)(evt);
}
public static void Unsubscribe&lt;T&gt;(Action&lt;T&gt; handler) {
if (_handlers.TryGetValue(typeof(T), out var handlers))
handlers.Remove(handler);
}
}

4.2 Explicit Tick Order
Continuous simulation uses shared state and an explicit tick order. Every tick the systems run in the same sequence. This eliminates ordering bugs and makes the simulation deterministic.
public class Simulation {
// Systems — instantiated once, persist for game lifetime
private readonly ConstructSystem    _constructs;
private readonly PowerSystem        _power;
private readonly LogisticsSystem    _logistics;
private readonly FluidSystem        _fluids;
private readonly MachineSystem      _machines;
private readonly EnemySystem        _enemies;
private readonly CombatSystem       _combat;
private readonly ProgressionSystem  _progression;
private readonly WorldStreamer      _streamer;
public void Tick(float dt) {
_state.Tick++;
// 1. World — load/unload chunks
_streamer.Tick(_state, dt);
// 2. Construct membership — flood-fill after block changes
_constructs.Tick(_state, dt);
// 3. Power — balance networks, apply shortage throttle
_power.Tick(_state, dt);
// 4. Logistics — advance belt slots, run inserters
_logistics.Tick(_state, dt);
// 5. Fluids — advance fluid networks
_fluids.Tick(_state, dt);
// 6. Machines — consume inputs, advance production, emit outputs
_machines.Tick(_state, dt);
// 7. Enemies — AI tick (LOD-gated by distance)
_enemies.Tick(_state, dt);
// 8. Combat — resolve damage, apply to blocks and entities
_combat.Tick(_state, dt);
// 9. Progression — check milestones, fire tier unlocks
_progression.Tick(_state, dt);
}
}
5. Key System Implementations
5.1 Construct Membership — Flood Fill
When a block is added or removed, the ConstructSystem recalculates membership using a flood fill from the changed block&apos;s neighbours.
public class ConstructSystem {
public void OnBlockRemoved(Block block, SimulationState state) {
var neighbours = GetAdjacentBlocks(block, state.Blocks);
if (neighbours.Count == 0) return;
// Flood-fill from each neighbour — find connected components
var seen       = new HashSet&lt;int&gt;();
var components = new List&lt;HashSet&lt;int&gt;&gt;();
foreach (var neighbour in neighbours) {
if (seen.Contains(neighbour.Id)) continue;
var component = FloodFill(neighbour, state.Blocks, seen);
components.Add(component);
}
if (components.Count == 1) return; // no split — done
// Split: first component keeps original construct
// Remaining components become new constructs
var original = state.Constructs.Get(block.ConstructId);
original.BlockIds = components[0];
original.Reclassify(state.Blocks);
for (int i = 1; i &lt; components.Count; i++) {
var newConstruct = state.Constructs.Create();
newConstruct.BlockIds = components[i];
newConstruct.Reclassify(state.Blocks);
foreach (var id in components[i])
state.Blocks.Get(id).ConstructId = newConstruct.Id;
}
EventBus.Publish(new ConstructSplitEvent {
Original = original,
NewConstructs = components.Skip(1)
.Select(c =&gt; state.Constructs.GetByBlockSet(c)).ToArray()
});
}
private HashSet&lt;int&gt; FloodFill(Block start,
BlockTable blocks, HashSet&lt;int&gt; seen) {
var result = new HashSet&lt;int&gt;();
var queue  = new Queue&lt;Block&gt;();
queue.Enqueue(start);
while (queue.Count &gt; 0) {
var current = queue.Dequeue();
if (!seen.Add(current.Id)) continue;
result.Add(current.Id);
foreach (var n in GetAdjacentBlocks(current, blocks))
if (!seen.Contains(n.Id)) queue.Enqueue(n);
}
return result;
}
}
5.2 Power Network Balance
public class PowerSystem {
public void Tick(SimulationState state, float dt) {
foreach (var network in state.PowerNetworks.Active) {
float supply = 0f, demand = 0f, turretDemand = 0f;
// Sum generators
foreach (var id in network.GeneratorIds) {
var block = state.Blocks.Get(id);
supply += block.GeneratorState.CurrentOutputKW;
}
// Discharge batteries to cover deficit
foreach (var id in network.BatteryIds)
supply += DischargeBattery(state.Blocks.Get(id), dt);
// Sum consumers — separate turrets
foreach (var id in network.ConsumerIds) {
var block = state.Blocks.Get(id);
if (block.Definition.Category == BlockCategory.Defense)
turretDemand += block.Definition.PowerDrawKW;
else
demand += block.Definition.PowerDrawKW;
}
float totalDemand = demand + turretDemand;
network.CurrentSupply = supply;
network.CurrentDemand = totalDemand;
// Apply power — turrets protected, others throttled
if (supply &gt;= totalDemand) {
SetAllOperating(network, state, 1f);
ChargeExcessToBatteries(network, state,
supply - totalDemand, dt);
} else if (supply &gt;= turretDemand) {
SetTurretsOperating(network, state, 1f);
float ratio = (supply - turretDemand) / demand;
SetNonTurretsOperating(network, state, ratio);
} else {
SetAllOperating(network, state, 0f);
EventBus.Publish(new PowerShortageEvent {
NetworkId = network.Id,
DeficitKW = totalDemand - supply
});
}
}
}
}
5.3 Enemy LOD Tick System
public class EnemySystem {
// Tick intervals by distance from player
private const float NEAR_INTERVAL =  0.05f; // 20Hz  &lt; 100m
private const float MID_INTERVAL  =  0.2f;  //  5Hz  100-300m
private const float FAR_INTERVAL  =  1.0f;  //  1Hz  300m+
public void Tick(SimulationState state, float dt) {
var playerPos = state.Player.Position;
foreach (var enemy in state.Enemies.Active) {
float dist = Vector3.Distance(enemy.Position, playerPos);
float interval = dist &lt; 100f ? NEAR_INTERVAL
: dist &lt; 300f ? MID_INTERVAL
:               FAR_INTERVAL;
enemy.TickAccumulator += dt;
if (enemy.TickAccumulator &lt; interval) continue;
enemy.TickAccumulator -= interval;
TickEnemy(enemy, interval, state);
}
}
private void TickEnemy(Enemy enemy, float dt,
SimulationState state) {
switch (enemy.State) {
case EnemyState.Idle:
UpdateIdleBehaviour(enemy, dt, state); break;
case EnemyState.Alert:
UpdateAlert(enemy, dt, state);          break;
case EnemyState.Attacking:
UpdateAttack(enemy, dt, state);         break;
case EnemyState.Retreating:
UpdateRetreat(enemy, dt, state);        break;
}
}
}
6. Rendering Architecture
6.1 Factory Block Rendering
Blocks are rendered using two strategies based on their category. Neither strategy uses per-block GameObjects.
// Strategy 1: GPU Instancing for functional blocks (machines, power, defense)
public class BlockInstanceRenderer {
private readonly Mesh     _mesh;
private readonly Material _material;
private Matrix4x4[]       _matrices;
private Vector4[]         _damageStates; // per-instance data
public void UpdateAndRender(List&lt;Block&gt; blocks) {
for (int i = 0; i &lt; blocks.Count; i++) {
_matrices[i] = blocks[i].LocalToWorld;
// Pack damage (0-1), running state, grime level into Vector4
float damage = 1f - (float)blocks[i].Durability
/ blocks[i].Definition.MaxDurability;
float running = blocks[i].MachineState?.IsOperating == true ? 1f : 0f;
_damageStates[i] = new Vector4(damage, running, 0, 0);
}
_material.SetVectorArray(&quot;_PerInstanceData&quot;, _damageStates);
Graphics.DrawMeshInstanced(_mesh, 0, _material, _matrices, blocks.Count);
}
}
// Strategy 2: Chunk mesh merging for structural blocks (walls, floors, foundations)
public class ChunkMeshBuilder {
public void RebuildChunk(Chunk chunk, BlockTable blocks) {
// Group structural blocks by material
var byMaterial = new Dictionary&lt;Material, List&lt;CombineInstance&gt;&gt;();
foreach (var id in chunk.BlockIds) {
var block = blocks.Get(id);
if (block.Definition.Category != BlockCategory.Structural) continue;
var mat = block.Definition.Material;
if (!byMaterial.ContainsKey(mat))
byMaterial[mat] = new List&lt;CombineInstance&gt;();
byMaterial[mat].Add(new CombineInstance {
mesh      = block.Definition.Mesh,
transform = block.LocalToWorld
});
}
// One merged mesh per material — minimum draw calls
chunk.StructuralMeshes.Clear();
foreach (var (mat, instances) in byMaterial) {
var merged = new Mesh();
merged.CombineMeshes(instances.ToArray());
chunk.StructuralMeshes[mat] = merged;
}
chunk.StructuralMeshDirty = false;
}
}
6.2 Belt Item Rendering
public class BeltItemRenderer {
// One renderer per item type — all iron plates across all belts = 1 draw call
private Dictionary&lt;string, ItemInstanceRenderer&gt; _byType = new();
public void Render(List&lt;BeltConnection&gt; belts, BlockTable blocks) {
// Clear previous frame positions
foreach (var r in _byType.Values) r.Clear();
foreach (var belt in belts) {
for (int i = 0; i &lt; belt.Slots.Length; i++) {
var slot = belt.Slots[i];
if (slot.ItemId == null) continue;
// Evaluate spline at slot position for smooth movement
float t = (float)i / belt.Slots.Length;
// Interpolate between previous and current for visual smoothness
float tSmooth = Mathf.Lerp(slot.PreviousT, t, _alpha);
Vector3 worldPos = belt.Spline.Evaluate(tSmooth);
if (!_byType.ContainsKey(slot.ItemId))
_byType[slot.ItemId] = new ItemInstanceRenderer(slot.ItemId);
_byType[slot.ItemId].Add(worldPos);
}
}
foreach (var r in _byType.Values) r.DrawInstanced();
}
}
6.3 Swarmer GPU Instancing
public class SwarmInstanceRenderer : MonoBehaviour {
[SerializeField] private Mesh     _crawlerMesh;
[SerializeField] private Material _instancedMaterial; // GPU skinning shader
private ComputeBuffer _positionBuffer;
private ComputeBuffer _animationBuffer;

7. World Streaming
The world is a uniform grid of chunks. Each chunk is 32×32 cells = 16m×16m at 0.5m cell size. Two independent radii control simulation and rendering.
public class WorldStreamer {
private const int CHUNK_SIZE   = 32;   // cells per side
private const int SIM_RADIUS   = 5;    // chunks — simulation active
private const int VIEW_RADIUS  = 3;    // chunks — GameObjects spawned
private const float CELL_SIZE  = 0.5f; // metres per cell
private Dictionary&lt;Vector2Int, Chunk&gt; _loaded = new();
public void Tick(SimulationState state, float dt) {
var centre = WorldToChunk(state.Player.Position);
// Expand — load chunks within sim radius
for (int x = -SIM_RADIUS; x &lt;= SIM_RADIUS; x++)
for (int z = -SIM_RADIUS; z &lt;= SIM_RADIUS; z++) {
var coord = centre + new Vector2Int(x, z);
if (!_loaded.ContainsKey(coord))
LoadChunk(coord, state);
}
// Contract — save and evict distant chunks
foreach (var coord in _loaded.Keys.ToList()) {
if (ChunkDistance(coord, centre) &gt; SIM_RADIUS + 1) {
SaveChunk(_loaded[coord]);
_loaded.Remove(coord);
EventBus.Publish(new ChunkUnloadedEvent { Coord = coord });
}
}
// Update active list on state
state.Chunks.SetActive(_loaded.Values.ToList());
}
// Network graphs span chunks — maintained separately
// Only nodes in loaded chunks participate in simulation
public void OnChunkLoaded(Chunk chunk, SimulationState state) {
foreach (var block in chunk.Blocks)
_powerNetworkManager.RegisterBlock(block, state);
EventBus.Publish(new ChunkLoadedEvent { Chunk = chunk });
}
}
// View layer responds to chunk events — spawns/despawns GameObjects
public class ChunkViewManager : MonoBehaviour {
void Start() {
EventBus.Subscribe&lt;ChunkLoadedEvent&gt;(OnChunkLoaded);
EventBus.Subscribe&lt;ChunkUnloadedEvent&gt;(OnChunkUnloaded);
}
void OnChunkLoaded(ChunkLoadedEvent e) {
if (IsInViewRadius(e.Chunk.Coord))
SpawnChunkView(e.Chunk);
}
void OnChunkUnloaded(ChunkUnloadedEvent e) {
DespawnChunkView(e.Coord);
}
}
8. Pathfinding
8.1 Flow Fields for Enemies
public class FlowField {
public Vector2Int       Target;
public Vector2[,]       Vectors;    // direction per cell
public bool             IsDirty;
// Built with Dijkstra from target outward — O(n) single pass
public void Build(WorldGrid grid) {
var open    = new Queue&lt;Vector2Int&gt;();
var visited = new bool[grid.Width, grid.Height];
Vectors = new Vector2[grid.Width, grid.Height];
open.Enqueue(Target);
visited[Target.x, Target.y] = true;
while (open.Count &gt; 0) {
var current = open.Dequeue();
foreach (var n in grid.GetNeighbours(current)) {
if (visited[n.x, n.y] || grid.IsBlocked(n)) continue;
Vectors[n.x, n.y] =
((Vector2)(current - n)).normalized;
visited[n.x, n.y] = true;
open.Enqueue(n);
}
}
IsDirty = false;
}
}
public class FlowFieldManager {
private Dictionary&lt;int, FlowField&gt; _fields = new();
// Each unique target construct gets one field
// Shared by ALL enemies targeting that construct
public FlowField GetOrCreate(int constructId,
Vector2Int target, WorldGrid grid) {
if (!_fields.ContainsKey(constructId)) {
var f = new FlowField { Target = target };
f.Build(grid);
_fields[constructId] = f;
}
return _fields[constructId];
}
// Called when terrain or constructs change in a chunk
public void InvalidateChunk(Vector2Int chunkCoord) {
foreach (var f in _fields.Values)
if (f.CoversChunk(chunkCoord)) f.IsDirty = true;
}
// Rebuild dirty fields asynchronously
public async Task RebuildDirtyFields(WorldGrid grid) {
var dirty = _fields.Values.Where(f =&gt; f.IsDirty).ToList();
foreach (var f in dirty)
await Task.Run(() =&gt; f.Build(grid));
}
}
// Enemy movement — just a vector lookup per tick
void MoveWithFlowField(Enemy enemy, FlowField field, float dt) {
var cell = WorldToCell(enemy.Position);
var dir  = field.Vectors[cell.x, cell.y];
enemy.Position += new Vector3(dir.x, 0, dir.y)
* enemy.Speed * dt;
}

public static class SaveManager {
private const int CURRENT_VERSION = 1;
public static void Save(Simulation sim, string path) {
var file = new SaveFile {
GameId    = sim.State.World.GameId,
SaveTime  = DateTime.UtcNow,
TickCount = sim.State.Tick,
Blocks    = sim.BlockSystem.Serialise(),
// ... each system serialises itself
};
string json    = JsonConvert.SerializeObject(file);
string tmpPath = path + &quot;.tmp&quot;;
// Atomic write — never corrupt an existing save
File.WriteAllText(tmpPath, json);
if (File.Exists(path))
File.Replace(tmpPath, path, path + &quot;.bak&quot;);
else
File.Move(tmpPath, path);
}
public static Simulation Load(string path) {
string json = File.ReadAllText(path);
var file    = JsonConvert.DeserializeObject&lt;SaveFile&gt;(json);
// Migrate old save versions
if (file.Version &lt; CURRENT_VERSION)
file = SaveMigrator.Migrate(file, CURRENT_VERSION);
var sim = new Simulation();
sim.BlockSystem.Deserialise(file.Blocks);
// ... each system restores itself
return sim;
}
}
10. Performance Guidelines
These are the rules that keep the game running at 60fps as the factory and battlefield scale. Every new system must be evaluated against them.
10.1 The Rules
Rule
Rationale
How to enforce
Never call GetComponent&lt;&gt; in Update()
GetComponent is a hash lookup — expensive in hot loops.
Cache references in Awake() or Start(). Use [SerializeField] for inspector-assigned references.
No per-frame memory allocation in simulation tick
GC pressure causes unpredictable frame spikes.
Use object pools for enemies, projectiles, particles. Use structs for event types. Pre-allocate lists with capacity.
No LINQ in hot paths
LINQ allocates enumerators on the heap.
Use for loops over arrays in simulation tick. LINQ is fine in editor code and one-time operations.
Belt simulation only ticks occupied slots
Empty belt cells must not tick.
Maintain a list of occupied slot indices per belt. Only iterate those.
Enemy AI ticks at distance-scaled frequency
500 enemies at 60Hz = frame destroyed.
LOD tick system (Section 5.3) is mandatory. Never add a per-frame enemy Update().
Chunk mesh rebuild is deferred and async
Rebuilding a chunk mesh blocks the main thread for several frames.
Mark chunks dirty. Rebuild on a job thread. Apply the new mesh at start of next frame.
Flow fields rebuild asynchronously
Field rebuild for a large world grid is expensive.
Mark fields dirty on block change. Rebuild on background task. Never rebuild synchronously on main thread.
All instanced renderers batch per type
One draw call per block/enemy type is the target.
Never create a MeshRenderer per block. Route all block rendering through BlockInstanceRenderer or ChunkMeshBuilder.
10.2 Object Pooling Pattern
Enemies, projectiles, belt items (as view objects), and particle effects must be pooled. Instantiate and Destroy are expensive — pooling eliminates runtime GC.
public class EnemyPool : MonoBehaviour {
[SerializeField] private GameObject _prefab;
private Queue&lt;EnemyView&gt; _pool = new();
public EnemyView Get(Enemy model) {
var view = _pool.Count &gt; 0 ? _pool.Dequeue()
: Instantiate(_prefab).GetComponent&lt;EnemyView&gt;();
view.Bind(model);
view.gameObject.SetActive(true);
return view;
}
public void Return(EnemyView view) {
view.gameObject.SetActive(false);
_pool.Enqueue(view);
}
}
